# Catering Booking System

## 📌 Overview
This is a full-stack web application developed using Node.js, Express, React, and MongoDB. The system allows users to create and manage catering bookings, while administrators can manage all bookings through a dashboard.

---

## 🚀 Features
- User Authentication (Login/Register)
- Create Booking
- View Bookings
- Edit Booking
- Delete Booking
- Admin Dashboard
- Approve / Cancel Orders

---

## 🛠️ Technologies Used
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Version Control: GitHub
- Deployment: AWS EC2
