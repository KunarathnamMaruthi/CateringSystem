# Eventbite Catering Booking System

## Project Overview

Eventbite Catering Booking System is a full-stack MERN web application developed to simplify catering service management and online event booking. The system allows customers to browse catering menus, create bookings, manage profiles, and interact with catering services through an easy-to-use interface. Administrators can manage menu items, customer bookings, and catering operations through a dedicated admin dashboard.

The project was deployed using AWS EC2 and managed using PM2. GitHub Actions was implemented for CI/CD automation.
